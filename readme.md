# Копии утилит `cat` и `grep`

Проект содержит реализацию консольных утилит `cat` и `grep`. Для каждой утилиты написаны тесты на Bash.

## Запуск `cat`

В папке /cat:
1. Сборка: `make s21_cat`
2. Запуск тестов (Linux): `bash ./s21_cat_test.sh` (должен быть установлен русский язык)
3. Использование: `./s21_cat [OPTION]... [FILE]...`

## Запуск `grep`

В папке /grep:
1. Сборка: `make s21_grep`
2. Запуск тестов (Linux): `bash ./s21_grep_test.sh` (должен быть установлен русский язык)
3. Использование: `./s21_grep [OPTION]... PATTERNS [FILE]...`
